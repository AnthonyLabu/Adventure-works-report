# Adventure-works-report - Business Intelligence Dashboard

**Tools:** Power BI Desktop | Power Query | DAX | Data Modelling  

**Course:** Microsoft Power BI Desktop for Business Intelligence (Maven Analytics)

### Business Question
How is Adventure Works Cycles performing across regions, products, and customers, and where are the biggest opportunities to improve revenue, profit, and customer value?

### What I did
- Played the role of Business Intelligence Analyst for Adventure Works Cycles 
- Connected and transformed multiple raw CSV files using Power Query (cleaning, merging, appending, creating conditional columns, and building a rolling calendar)
- Designed a proper relational data model using a star schema (fact and dimension tables, relationships, hierarchies)
- Created key DAX measures for revenue, profit, orders, returns, and time intelligence
- Built interactive multi-page reports to track KPIs, compare regional performance, analyse product trends, and identify high-value customers

### Key Skills Demonstrated
- Data cleaning and transformation with Power Query
- Relational data modelling 
- DAX (calculated columns, measures, filter context, time intelligence)
- Interactive report design (KPIs, slicers, maps, drill-through, bookmarks)

### Outcome
Delivered a professional, end-to-end business intelligence solution that enables management to monitor performance and make data-driven decisions.
